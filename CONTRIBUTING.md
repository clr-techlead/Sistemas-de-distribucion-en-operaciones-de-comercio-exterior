# Contributing
Thanks for your interest in improving this project.
## Local setup
1. Install Node.js.
2. Run `npm install`.
3. Create `.env.local` with your own `API_KEY`.
4. Run `npm run dev`.
## Development workflow
- Create a focused branch for each change.
- Keep commits small and descriptive.
- Update documentation when behavior changes.
- Run the available CI checks before opening a pull request.
## Pull requests
Please describe the problem, the proposed solution, and how you tested it. Do not commit API keys, credentials, or generated build artifacts.
